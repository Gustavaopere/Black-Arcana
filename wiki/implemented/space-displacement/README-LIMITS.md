# Space & Displacement — Hard safety ceilings

- Threshold Gate: ≤ 32 transfers/s.
- Anchor Recall: projectile age ≤ 600 ticks; range ≤ 128 blocks.
- Reciprocal Transposition: ≤ 16 swaps/s.
- Vector Reversal: resulting speed ≤ 2.5 blocks/tick; ≤ 4 targets/application.
- Safe-position search: ≤ 64 candidates.

Estes números são limites técnicos máximos confirmados; não são automaticamente os números finais de balanceamento de Stage 08.
