# Glossário curto

- **Host:** mod/interface que expõe o spell ao jogador.
- **Authority:** sistema que decide o estado/mutação real.
- **Hard ceiling:** limite absoluto de segurança.
- **TBD:** ainda não fechado; não é valor implícito.
- **Fail-closed:** funcionalidade dependente fica indisponível quando não pode ser provada com segurança.
