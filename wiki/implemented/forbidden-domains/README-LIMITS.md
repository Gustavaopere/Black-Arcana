# Forbidden Domains — Hard safety ceilings

- radius ≤ 24 blocks;
- duration ≤ 1,200 ticks;
- tracked participants/entities ≤ 64/domain;
- active domains ≤ 8/server;
- active domains ≤ 1/owner;
- restoration/work metadata ≤ 512 recorded positions.

Estes são limites absolutos de segurança, não necessariamente valores finais de gameplay.
