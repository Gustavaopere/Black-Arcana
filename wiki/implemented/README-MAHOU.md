# Mahou origin/reconciliation

O projeto começou com inspiração/reprodução funcional de conceitos do Mahou distribuídos entre providers mágicos do pack. A Wiki deve mapear essa origem por mecânica quando houver evidência nos planos/histórico, mas o estado atual do runtime e a authority dos providers instalados prevalecem.

Não assumir que toda mecânica atual ainda corresponde 1:1 ao Mahou; os stages 05–07 já introduziram contratos próprios do Black Arcana.
