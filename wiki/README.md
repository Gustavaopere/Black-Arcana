`docs/reference` e `docs/design` contêm referências, candidatos e especificações importantes para desenvolvimento, mas **não são automaticamente gameplay**. Para uma mecânica aparecer aqui como disponível, ela precisa estar registrada/wired no runtime atual ou ser infraestrutura efetivamente executada/testada.
