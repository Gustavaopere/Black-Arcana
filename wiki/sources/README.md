# Fontes e Proveniência

Esta pasta documenta as fontes usadas para desenhar/adaptar feitiços.

## Regras

- Priorizar documentação oficial, código do provider e materiais canônicos do próprio projeto para comportamento técnico.
- Para inspiração em personagens/obras, usar fontes públicas confiáveis e registrar apenas capacidades em nível abstrato.
- Não copiar texto descritivo, nomes exclusivos de golpes, símbolos proprietários, arte, diálogos ou sequências específicas protegidas.
- Respect Threads, wikis e bases de fãs podem ser usados como índice de feats, mas devem ser tratados como fontes secundárias e, quando possível, cruzados com material oficial.
- Toda adaptação deve receber nome, números, custos, limites e apresentação próprios do Black Arcana.
