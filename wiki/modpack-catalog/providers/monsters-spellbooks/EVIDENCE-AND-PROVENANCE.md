## Why the 98-entry inventory is still closed semantically

`ModSpellRegistry` at the public head contains 98 explicit `registerSpell(...)` registrations.

A repository compare from `823532a3e4f865ad3b2f019c09f4acf3f4f451a5` (2026-08-27) to `1ab9b72af2ea44c3c8b816e665d06531ea44ddc2` (2026-09-01) covers the public work interval around releases 0.0.16.2 and 0.0.16.3. That compare changes spell/effect/equipment/resources, but **does not modify `ModSpellRegistry.java`**.

The public registry inventory is therefore stable across that release work interval. Combined with the exact release notes—which do not report spell registration additions/removals—this is sufficient to close the current 98-registration semantic inventory while still refusing exact binary internals.

## License/provenance caution

CurseForge currently displays the project as MIT License. The inspected repository's `gradle.properties` still declares `mod_license=All Rights Reserved`, and the repository search exposes only the NeoForge template license file rather than a clear project license file at the inspected head.

Black Arcana therefore treats this source as **interoperability/catalog evidence only**. This phase paraphrases behavior and records identities/counts; it does not copy provider code, assets, text, models, sounds or implementation.

Any future reuse beyond clean-room observation requires a separately verified compatible license/provenance decision.
