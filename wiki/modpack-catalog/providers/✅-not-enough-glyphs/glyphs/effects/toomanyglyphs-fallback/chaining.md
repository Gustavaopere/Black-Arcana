# Chaining

- Registry: `toomanyglyphs:chaining`
- Class: NEG `EffectChaining`
- Active because `toomanyglyphs` is absent.
- Tier: **II**; default mana: **300**
- Semantics: chains subsequent resolution through nearby eligible targets/blocks with provider-configured search/target bounds; AOE/Pierce/Sensitive/Randomize alter chaining behavior.
- Acquisition: Manipulation Essence + 3 Chains + Lapis Block + Redstone Block + Source Gem Block.
- Boundary: provider chaining loop remains authority; no BA duplicate chain proc.
