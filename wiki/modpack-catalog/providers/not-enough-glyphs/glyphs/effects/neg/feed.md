# Feed

- Registry: `not_enough_glyphs:feed`
- Class: `EffectFeed`
- Status: enabled; NEG-native
- Tier: **II**; default mana: **30**; school: Conjuration
- Semantics: consumes valid food from caster inventory to feed a non-undead living target and applies `stuffed` for 400 ticks, amplifier capped at 9. Randomize changes food selection.
- Config: `foodxplosion_chance` default 0.1; `stuffed_crush_multiplier` default 0.25.
- Acquisition: 6 food-tag items + Conjuration Essence.
- Boundary: Stuffed/crush event path is provider authority, not Black Arcana Backlash.
