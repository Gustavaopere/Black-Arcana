# Missile

- Registry: `arsomega:missile`
- Class: NEG `MethodMissile`
- Active because `arsomega` is absent; historical namespace preserved.
- Tier: **II**; default mana: **20**
- Semantics: creates NEG `MissileProjectile`; speed, split, gravity, duration, AOE and related augments modify provider projectile behavior. Server resolves spell effects on hit/expiration.
- Acquisition: 2 Firework Rockets + Air Essence + Fire Essence.
- Boundary: provider projectile/resolver authority; no BA duplicate missile loop.
