## Blackout exception

The current project page describes Blackout as an anti-magic field and associates its broader-project acquisition with the Enraged Dead King. Exact File `6342780` does register `traveloptics:blackout`, but the exact audit found:

- `AbstractUniqueSpell.allowCrafting() = false`;
- no direct structured-data acquisition reference for `blackout`;
- no provider-owned reference to `TOSpells.BLACKOUT_SPELL` outside the registry.

Accordingly, the semantic phrase is retained as publisher context while survival reachability remains **UNVERIFIED / FAIL-CLOSED**. See `BLACKOUT-VERSIONED-ACQUISITION-BOUNDARY.md`.
