## Semantic disposition

Sky Aesthetics is a client rendering/configuration API for resource-pack-defined skies.

The current line exposes visual definitions for objects such as:

- sun/moon;
- stars and shooting stars;
- constellations;
- clouds;
- fog;
- sky/sunset colors;
- dimension/biome-conditioned sky presentation.

These surfaces do not create server gameplay state, spell identities, glyphs, rituals, rites, abilities, entities or player-owned magical actions. The 2.0.13-beta line also removes the default skybox/default constellation, reinforcing that the base mod is a rendering framework rather than a fixed gameplay roster.
