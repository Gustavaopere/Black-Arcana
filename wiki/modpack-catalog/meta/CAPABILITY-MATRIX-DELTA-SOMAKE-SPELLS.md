## School implications

### Order

Somake Symmetry already consumes geometric/balanced presentation and some control space. Order is not automatically equivalent to Symmetry; approved Order content must express actual law, seal, constraint, rule imposition or causal governance not already supplied by Somake or other providers.

### Blood

Somake publicly demonstrates damage-sharing, blood zones, damage negation and grimoire Blood progression. Black Arcana Blood/Blood Binding candidates must compare against these semantics and against Iron's Blood before approval. Similar theme is not a bridge.

### Infernal

Somake's Soul Fire/Infernal Fire ritual path directly occupies infernal progression space, alongside Cataclysm/Ignis/Soul Fire providers. Black Arcana Infernal identity needs a distinct forbidden-magic contract rather than another fire/soul-fire upgrade chain.

### Aqua / elemental

The current pack contains Somake Aqua and deprecated T.O Magic 1.21.1 alpha simultaneously. No new Black Arcana Aqua school should be proposed. Existing provider authority must be resolved in runtime QA before any adapter assumes which registry/school is canonical.

### Chaos

Somake's large elemental attack library can consume visual/action space but does not by itself prove entropy/probability/reality-law Chaos semantics. Unknown Somake content still blocks claims that a particular generic effect is absent until the full registry is known.

## Runtime safety note

Guardian/Blessed/Cursed links, The Rose's Secret and Ignis Shield are especially sensitive to event ordering, damage cancellation/redirection and proc chains. Any future interop must preserve Black Arcana's rule that Backlash does not generate normal offensive proc chains and must prevent double-processing.

## Unknown-content rule

The publisher states `over 50` spells while the public changelog exposes only a subset of names. Any semantic gap analysis must reserve the unenumerated portion as `UNKNOWN PROVIDER SPACE` until the exact 1.0.8-fix registry or publisher-native complete documentation is available.
