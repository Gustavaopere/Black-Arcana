# Arcana Hemática e Vincular

## Estado

`CONCEITO / PESQUISA — EXPANSÃO SOBRE RUNTIME JÁ EXISTENTE`

## Host pretendido

A disciplina hemática deve usar a escola/identidade de **Blood** já existente no ecossistema mágico instalado, com Black Arcana coordenando os contratos próprios que forem implementados. O objetivo não é criar uma segunda mana.

## Invariante

Feitiços desta disciplina não usam mana normal. O combustível deve vir de sangue fisiológico real ou de sangue armazenado/vinculado segundo o contrato de `wiki/systems/blood-reservoir/`.

## Relação com funcionalidades atuais

Já existem no Black Arcana mecanismos reutilizáveis como:

- Blood Price;
- Equilibrium Rite;
- Sanguine Harvest;
- Law of Recurrence;
- Sympathetic Wound;
- Mortal Ledger / Soul Anchor / Spirit Sight, quando a interação for espiritual e não hemática.

Essas mecânicas não devem ser renomeadas como se já implementassem todo o novo sistema de reservatório/vínculo.

## Vínculo

`CONJURADOR ⇄ VÍNCULO ⇄ FONTE`

A fonte deve possuir sangue real para satisfazer custos hemáticos. Vida/energia vital, alma/espírito e mana são recursos distintos e não se convertem automaticamente em sangue.

## Catálogo

Os feitiços individuais serão classificados entre:

- sangue próprio;
- drenagem de alvo;
- consumo de fonte vinculada;
- consumo de reservatório em mB;
- transferência/redistribuição;
- maldição/contrato hemático;
- suporte/defesa hemática.
