# Black Arcana

Black Arcana is a NeoForge 1.21.1 / Java 21 project that rebuilds selected dark-magic gameplay concepts as an original, balanced and modular ecosystem integrated with the magic/RPG mods used by the pack.

The project is a clean-room implementation. Mahou Tsukai is a design reference only: no source code, assets, models, sounds or protected implementation are copied.

The canonical engineering plan lives in [`plans/`](plans/README.md). New implementation sessions must read `plans/README.md`, `plans/STATUS.md`, `plans/DECISIONS.md`, then the active stage README and task files before changing code.
