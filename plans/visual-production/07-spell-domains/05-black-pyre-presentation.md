# 07.05 — Black Pyre Presentation

## State

`DEFERRED VISUAL PRODUCTION / RUNTIME VISUAL-PLANE SEMANTICS ALREADY CANONICAL`

The numbered Black Flame plan remains authoritative for the bounded frontier, `COSMETIC` mode, entity/terrain independence, world safety and degradation codes. This file owns the concrete presentation direction only.

## Extracted identity

Black Pyre is an original forbidden soul-fire presentation with aggressive visual propagation. It must read as Black Arcana Black Flame rather than vanilla fire with only a recolor/cosmetic skin.

That is an art-direction constraint, not permission to copy Mahou or another mod's flame assets, shaders, particles, sounds or animation.

## Runtime-derived presentation

The visual layer consumes the bounded server-authored Black Pyre frontier/state. It must not:

- create its own propagation graph;
- invoke vanilla fire/random-tick spread;
- expand radius/cells beyond server state;
- imply that terrain mutation succeeded when the terrain plane was denied;
- become damage/status authority.

`COSMETIC` means the visual plane may exist with zero block mutation. Terrain failure may degrade to/continue cosmetic presentation when the runtime explicitly permits it, but presentation must distinguish cosmetic propagation from successful persistent terrain mutation where that distinction affects player understanding.

## Deferred assets

Final flame texture/particle/shader/model choices, palette, animation rhythm, cast telegraph, impact treatment and audio are intentionally TBD until visual production resumes. Reusable asset tooling/source-art validation belongs to `minecraft-mod-factory`; Black Arcana retains this spell-specific identity and state mapping.
