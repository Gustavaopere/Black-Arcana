# 05 — Casting & UX

Deliver direct, low-clutter casting after server contracts and integrations are stable.

## Goals
No universal staff requirement; no permanent extra mana HUD; fast loadouts; readable failure reasons; controller/keybind accessibility where practical.

## Tasks
- Input and loadouts.
- Radial selection.
- Contextual HUD/cast feedback.
- Accessibility/client configuration.

## Exit criteria
A player can equip/select/cast Black Arcana spells through a concise workflow, with all gameplay validation still server-authoritative.
