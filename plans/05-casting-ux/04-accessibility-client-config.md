# 05.04 — Accessibility & Client Configuration

## Options
HUD scale/anchor, reduced screen effects, particle density, radial hold/toggle behavior, cast feedback intensity and motion/flash reductions where relevant.

## Rule
Client preferences may reduce presentation but never alter server damage, cooldown, costs or world-effect policy.

## Acceptance
Settings persist locally, are safe with missing config entries and never enter gameplay validation packets except where input semantics require it.
