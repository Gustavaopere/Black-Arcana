# 09 — Hardening & Release

Validate the completed system under real modpack conditions before calling it finished.

## Tasks
- Compatibility/test matrix.
- Performance/profiling.
- Dedicated-server and multiplayer abuse tests.
- World/player-data upgrade strategy.
- Release checklist and provenance/license audit.

## Exit criteria
CI and chosen modpack smoke profiles are green, persistence upgrades are tested, performance budgets are met, provenance is auditable and release dependencies/configs are documented.
