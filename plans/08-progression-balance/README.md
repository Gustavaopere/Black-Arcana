# 08 — Progression & Balance

Close the power curve after the real content exists, using the RPG system and integrated magic resources rather than repetitive mana-cap grinding.

## Tasks
- Knowledge/unlock progression.
- RPG attributes/mastery gates.
- Quantitative spell budget model.
- Caps/diminishing returns/exploit controls.
- Server presets including conservative modpack defaults.

## Exit criteria
All spells have measurable tier budgets, progression paths and caps; no known unbounded scaling/loop survives the test matrix.
