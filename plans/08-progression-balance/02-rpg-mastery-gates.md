# 08.02 — RPG Attributes & Mastery Gates

## Objective
Use canonical RPG attributes/masteries/perks as Black Arcana's character-growth layer.

## Rules
- Define which attributes scale damage, range, duration, efficiency or control.
- Mastery XP awarded for meaningful successful use, with anti-spam/diminishing rules.
- Perks modify bounded parameters, never bypass world safety.
- No circular event chains between Black Arcana and RPG integration.

## Acceptance
Automated tests prove gates/modifiers and bounded mastery gain for repeated trivial casts.
