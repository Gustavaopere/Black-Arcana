# 08.05 — Server Config Presets

## Presets
At minimum design `SAFE`, `BALANCED` and `CHAOTIC/FULL` profiles without hiding individual per-feature controls.

## SAFE
Temporary/cosmetic world effects, conservative domain size, strict resurrection/projectile caps.

## BALANCED
Intended modpack default: impactful entity combat, limited reversible world impact, meaningful resource/cooldown costs.

## CHAOTIC/FULL
Explicit opt-in for destructive terrain effects; still bounded by technical safety budgets.

## Acceptance
Preset loading is deterministic, documented and never changes technical hard safety ceilings unless explicitly designed/tested.
