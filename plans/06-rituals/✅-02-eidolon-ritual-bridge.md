# 06.02 — Eidolon Ritual Bridge

## Objective
Use Eidolon's supported ritual/occult systems for Black Arcana unlocks/effects where stable APIs exist.

## Work
Map Black Arcana ritual requirements to supported Eidolon content; keep Black Arcana progression and world-safety preflight authoritative for Black Arcana outcomes.

## Fallback
If a required extension cannot be expressed through public/stable Eidolon hooks, use the Black Arcana grand-ritual engine with Eidolon ingredients/blocks rather than patching internals by default.

## Acceptance
One production ritual demonstrates deterministic registration, component consumption and server-side unlock/result.
