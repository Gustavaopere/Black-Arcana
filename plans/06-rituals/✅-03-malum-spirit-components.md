# 06.03 — Malum Spirit Components

## Objective
Make soul magic materially interact with Malum's spirit economy.

## Work
Define spirit-type/count predicates and transactional consumption for selected rituals. Prevent reward→cost loops that produce net-positive infinite spirits.

## Acceptance
Tests cover insufficient/mixed spirits, concurrent activation, cancellation and exact consumption. Missing Malum disables dependent ritual content rather than making it free.
