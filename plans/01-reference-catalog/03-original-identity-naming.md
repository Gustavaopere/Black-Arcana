# 01.03 — Original Identity & Naming

## Objective
Build a coherent Black Arcana vocabulary independent from Mahou Tsukai and fiction-specific names.

## Work
- Name schools/domains, spells, ritual categories and status effects.
- Define concise lore principles: forbidden knowledge, soul economy, projection, curses and spatial arcana.
- Define visual language for glyphs/sigils without copying existing assets.
- Produce old-concept → Black Arcana concept mapping for internal planning only.

## Acceptance
Player-facing identifiers, text and art briefs are original and internally consistent. No implementation depends on reference names.
