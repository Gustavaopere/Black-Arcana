# 01.02 — Classification Matrix

## Objective
Prevent feature creep and redundant magic.

For each catalog item assign:
- disposition: KEEP / REIMAGINE / MERGE / DROP / DEFER;
- Black Arcana domain;
- invocation: direct cast / weapon cast / ritual / passive / grand ritual;
- preferred host: core / Iron's / Ars / Eidolon / Malum / composite;
- cost provider;
- world-effect mode;
- multiplayer risk;
- progression tier.

## Acceptance
Every candidate has one disposition and rationale. Duplicate concepts are merged before implementation. Items whose only value is extreme power/destruction are dropped or redesigned.
