# 01.01 — Reference Feature Inventory

## Objective
Create a clean-room behavioral catalog of candidate mechanics.

## Capture per mechanic
- Publicly observable behavior and fantasy.
- Inputs/targets/range/duration.
- Why it is interesting.
- Problems in the reference experience: OP scaling, busywork, staff lock, HUD clutter, griefing, repetition.
- Whether an equivalent already exists in Iron's, Ars, Eidolon or Malum.

## Scope
Include active spells, boundaries/ritual-like effects, projection/weapon systems, displacement, black flame, death/life mechanics, divination/familiars and domain/reality-altering concepts.

## Acceptance
Catalog is complete enough that later classification does not require inspecting closed implementation code.
